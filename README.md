# CYBERMIND 3D // Portal de Fabricación Aditiva

Ecosistema web responsivo con diseño HUD táctico inspirado en interfaces cibernéticas de Terminator y Depredador.

## 🚀 Despliegue Inmediato por Consola

Abre tu terminal en la carpeta del proyecto y ejecuta secuencialmente:

```bash
git init
git add .
git commit -m "feat: setup full cyber-hud architecture with actions"
git branch -M main
git remote add origin https://github.com
git push -u origin main
```

## ⚙️ Activación CI/CD (GitHub Actions)
1. Ve a los **Settings** de tu repositorio en GitHub.
2. Ingresa a la sección **Pages**.
3. Cambia la opción *Source* de "Deploy from a branch" a **GitHub Actions**.
